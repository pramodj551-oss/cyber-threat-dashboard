# 🛡️ Cyber Threat Intelligence Dashboard

**Real-time Network Anomaly Detection Dashboard**

Built by **Pramod Prakash Jadhav** as part of the AI & ML Essentials programme at **IIT Patna (Vishlesan i-Hub)**.

## Features
- 📈 Live network traffic chart (Normal vs Malicious packets/sec)
- 🌍 Geo-origin attack map (world map with live attack dots)
- 📊 Attack type classifier (SQL Injection, Brute Force, DDoS, Port Scan, Phishing, Malware C2)
- 🚨 Live threat feed with severity filtering (CRITICAL / HIGH / MEDIUM / LOW)
- 🔎 IP reputation scoring for top threat IPs
- 🎛️ Sidebar controls — pause/resume, severity filter, attack type filter

## Tech Stack
- Python · Streamlit · Plotly · Pandas · NumPy
